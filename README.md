# tunarr-logos

Simple channel logos for a home Tunarr → Plex Live TV setup: a short genre word
and MOVIES/SERIES on a solid color, 512×512 PNG.

Plex Web loads XMLTV channel logos directly in the browser, so they need a
public HTTPS URL; these files are referenced as
`https://raw.githubusercontent.com/newharry/tunarr-logos/main/<file>.png`.

Generated by `make-logos.ps1` in the (private) homelab setup.
